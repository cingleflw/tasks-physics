# Физический тест с конструктором наборов задач

Тест с конструктором (клиент-серверное приложение). Ученик выбирает тему по физике за 6–8 класс, а программа генерирует для него задачи со случайными числами: условие каждый раз новое, правильный ответ вычисляется автоматически.

**Прогресс:** выполнено 2 из 6 пунктов · 10 тем · 62 рандомизированные задачи

## Запуск

Задачи загружаются из JSON-файлов с помощью `fetch()`, поэтому страницу нужно открывать через локальный веб-сервер. Если открыть `index.html` двойным кликом (адрес вида `file://...`), браузер запретит загрузку файлов и при выборе темы покажет сообщение об ошибке.

**WebStorm.** Откройте `index.html` и нажмите на значок браузера в правом верхнем углу редактора (или *Open In → Browser*). Страница откроется со встроенного сервера, например `http://localhost:63342/tasks-physics/index.html`.

**Терминал** (нужен Python 3):

```bash
cd tasks-physics
python3 -m http.server 8000
```

Затем откройте в браузере http://localhost:8000.

Выберите тему и введите количество задач. Пока нет интерфейса тестирования (п. 6), сгенерированные задачи с ответами выводятся в консоль браузера (F12 → Console).

Имя файла темы совпадает с атрибутом `data-topic` её кнопки в `index.html`.

## Формат задачи

Файл темы содержит её номер, класс, название и список шаблонов задач:

```json
{
    "id": "7_mechanics",
    "grade": 7,
    "title": "Механическое движение",
    "tasks": [
        {
            "id": 3,
            "text": "Поезд, двигаясь равномерно, прошёл {s} км за {t} ч. Найдите скорость поезда.",
            "params": {
                "v": { "min": 40, "max": 120, "step": 10 },
                "t": { "min": 2, "max": 6 }
            },
            "derived": {
                "s": "v * t"
            },
            "answer": "v",
            "unit": "км/ч"
        }
    ]
}
```

| Поле | Обязательное | Описание |
|---|---|---|
| `id` | да | Номер шаблона внутри темы |
| `text` | да | Текст условия. `{имя}` заменяется значением величины, `{имя.поле}` — полем выбранного варианта |
| `params` | да | Случайные параметры: `{ "min": 1, "max": 5, "step": 0.5 }` (шаг по умолчанию 1) или `{ "choices": [ ... ] }` |
| `derived` | нет | Вычисляемые величины в виде `"имя": "формула"`; считаются по порядку и могут использовать предыдущие |
| `answer` | да | Формула правильного ответа |
| `unit` | да | Единица измерения ответа |
| `precision` | нет | Количество знаков после запятой в ответе (по умолчанию 2) |

В формулах можно использовать числа, имена величин, знаки `+ - * /` и скобки. Варианты из `choices` могут быть объектами — так вещество выбирается вместе со своими свойствами:

```json
"params": {
    "material": { "choices": [
        { "name": "меди", "ro": 8.9 },
        { "name": "алюминия", "ro": 2.7 }
    ] },
    "V": { "min": 5, "max": 50, "step": 5 }
},
"derived": {
    "m": "material.ro * V"
},
"text": "Деталь из {material.name} имеет массу {m} г. Плотность {material.name} равна {material.ro} г/см³. Найдите объём детали."
```

Из шаблона получается задача, которая хранит свои случайные параметры:

```js
{
    topicId: "7_mechanics",
    taskId: 3,
    params: { v: 110, t: 2 },   // сохранённые случайные значения
    text: "Поезд, двигаясь равномерно, прошёл 220 км за 2 ч. Найдите скорость поезда.",
    answer: 110,
    unit: "км/ч"
}
```

**Правила составления задач:**
- ответ при заданной точности `precision` должен получаться точным, иначе в условии пишется «Ответ округлите до десятых»;
- все нужные константы (плотность, удельная теплоёмкость, g = 10 Н/кг) приводятся в условии;
- единицы измерения пишутся сокращённо («ч», «мин», «кг»), чтобы текст не зависел от склонения числительных.
