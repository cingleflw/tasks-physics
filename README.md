Тест с конструктором (клиент-серверное приложение) 
1) Разработать систему рандомизации и её хранение в условиях задачи.
2) Набрать базу из не менее чем 10 тем из любой области, в каждой из которых не менее 5 рандомизированных задач. 
3) Реализовать на серверной части проверку ответов пользователей. 
4) Реализовать конструктор для добавления новых тем и задач. 
5) Реализовать случайный выбор заданий по выбранным пользователем темам. 
6) Реализовать прохождение тестирования с отображением задач пользователям и возврат информации о тестировании (количество правильных задач, количество ошибок, время и т. п.).
